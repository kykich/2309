# Зависимости проекта.

# Проект почти не требует сторонних пакетов: сервер, отдача файлов,
# обработка форм — всё на стандартной библиотеке Python 3.7+ (http.server,
# urllib, json, re, threading, mimetypes, pathlib и т.д.).
#
# Внешняя зависимость — пакет \mcp\ (Model Context Protocol): нужен ТОЛЬКО
# для MCP-слоя (подключение к MCP-серверу, list_tools/call_tool, см.
# rtk_app/mcp_client.py, client.py, yandex_calendar_server.py). Зависимость
# ОПЦИОНАЛЬНАЯ: веб-сервер запускается и без неё — тогда статус MCP в
# интерфейсе будет «недоступен (не установлен пакет mcp)».
#
# Требуется Python >= 3.9 (для пакета mcp).
#
# Установка:  pip install -r requirements.txt
